
# PGP-DSBA Projects

Applied Data Science & Business Analytics projects completed during the 
Postgraduate Program in Data Science & Business Analytics (PGP-DSBA), 
covering SQL, Python, statistics, and machine learning.

## Projects

### 1. New Wheels — SQL (`NewWheels_TSALA_...`)
Diagnosed declining sales and customer retention using MySQL: data 
aggregation, window functions, subqueries, and joins, producing insights 
for a Quarterly Business Report.

### 2. FoodHub Order Analysis — Python Foundations (`PYF_Project_TSALA_...`)
Exploratory data analysis (univariate/bivariate) on food aggregator order 
data to generate actionable business insights.

### 3. E-news Express — Business Statistics (`ENews_Express_LearnerTSALA_...`)
A/B testing and hypothesis testing in Python to evaluate the effectiveness 
of a new landing page on subscriber conversion.

### 4. ReCell — Supervised Learning: Foundations (`SLF_ProjectTSALA_...`)
Built a linear regression model to develop a dynamic pricing strategy for 
used and refurbished devices.

### 5. INN Hotels — Supervised Learning: Classification (`Project_TSALA_SLC_DSBA_INNH...`)
Logistic regression and decision tree classification model to predict 
booking cancellations, evaluated with AUC-ROC and addressing multicollinearity.

### 6. EasyVisa — Ensemble Techniques and Model Tuning (`TSALA_Project_Full_Code_Noteb...`)
Bagging and boosting ensemble models with hyperparameter tuning to predict 
visa approval outcomes.

### 7. Trade&Ahead — Unsupervised Learning (`USL_Project_TSALA_LearnerNote...`)
KMeans and hierarchical clustering with cluster profiling to group stocks 
by financial attributes.

## Tools & Libraries
Python, MySQL, pandas, NumPy, scikit-learn, matplotlib, seaborn
